# Amazing Rigging

Bone Collection visual management and rigging workflow tool for Blender 5.0+.

## Features

- **Sidebar Panel**: View all bone collections of the active armature when a bone is selected
- **Bone Properties Panel**: Per-bone properties in the Properties > Armature Data panel
- **Layer Editor**: Visual grid editor for bone collection layout
- **Split Rules**: Customizable bone classification rules with prefix/exact matching
- **Auto Classification**: Automatically classify bone collections based on naming conventions

## Installation

1. Download the `.zip` file from the [Releases](https://github.com/lifang/AmazingRigging/releases) page
2. In Blender: Edit > Preferences > Add-ons > Install... > Select the `.zip` file
3. Enable "Rigging: Amazing Rigging"

Or install via Blender Extensions (coming soon).

## Usage

### Sidebar Panel
- Press `N` in the 3D Viewport to open the Sidebar
- Navigate to the "Amazing Rigging" tab
- Select a bone to see all its bone collections

### Bone Properties
- Select an armature object
- Go to Properties > Armature Data > Bone Properties
- Configure per-bone settings

### Split Rules
- Go to Properties > Armature Data > Split Bones Rules
- Configure prefix/exact match rules for bone classification
- Click "Init Amazing Rigging UI" to apply

## Requirements

- Blender 5.0 or later
